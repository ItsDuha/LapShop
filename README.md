# LapShop

A learning project built to practice developing a complete e-commerce web application using ASP.NET Core MVC, with a focus on application functionality, backend logic, database integration, and RESTful APIs.

## Technologies

- ASP.NET Core MVC
- C#
- Entity Framework Core
- SQL Server
- ASP.NET Core Identity
- JWT Authentication
- RESTful APIs
- HTML, CSS, JavaScript, jQuery
- Bootstrap
- Swagger

## Features

- User authentication using ASP.NET Core Identity
- JWT authentication for RESTful APIs
- Product and category management
- Product filtering and pagination
- Shopping cart and order placement
- Admin dashboard
- API documentation using Swagger

## What I Learned

- Building ASP.NET Core MVC applications and implementing CRUD operations
- Understanding frontend-backend communication in APIs
- Working with Entity Framework Core, LINQ, and SQL Server
- Implementing authentication with Identity and JWT
- Understanding when design patterns, such as the Repository Pattern, are useful and when they may not be necessary
- Testing RESTful APIs using Postman
- Designing relational databases
- Integrating a frontend template with backend functionality
